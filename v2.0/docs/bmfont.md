This document explains how to generate the BMFont files at a glance

When generating the BMFont, use AngelCode's BMFont generator

Make sure P92 Sans is already installed

The **font settings** are as follows:

Font: P92 Sans

Size: 8px

Do not include kerning pairs

Outline thickness: 1 (or keep it 0 if you don't plan to make it an outlined font)

The **export options** are as follows:

Padding:

- top: 0
- right: 1
- bottom: 1
- left: 0

Spacing:

- x: 0
- y: 0
